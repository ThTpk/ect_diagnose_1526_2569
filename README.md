# ผังคำวินิจฉัย กกต. ที่ ๑๕๒๖/๒๕๖๙

ถอดข้อความคำวินิจฉัยคณะกรรมการการเลือกตั้ง เรื่องการเลือกสมาชิกวุฒิสภา พ.ศ. ๒๕๖๗ (ไฟล์สแกน 114 หน้า) และทำเป็นเว็บเพจกราฟความเชื่อมโยงว่าใครพูดถึงใคร ว่าอย่างไร แยกตามประเด็นที่พิจารณา

## ไฟล์

| ไฟล์ | คืออะไร |
|---|---|
| `diagnose.pdf` | เอกสารต้นฉบับ (ภาพสแกน ไม่มีชั้นข้อความ) |
| `diagnose.md` | ข้อความที่ถอดจาก PDF ทุกหน้า มีเครื่องหมาย `<!-- page N -->` บอกเลขหน้า |
| `diagnose_ocr_report.md` | รายงานตรวจจุดที่อาจถอดข้อความไม่ได้หรือไม่แน่ใจ |
| `web/index.html` | เว็บเพจที่สร้างแล้ว เปิดคู่กับโฟลเดอร์ `web/pages/` |
| `web/template.html` | แม่แบบหน้าเว็บ (D3) |
| `web/graph/` | ข้อมูลความเชื่อมโยงที่สกัดจากเอกสาร (`chunk_*.json`) และรายชื่อผู้ถูกร้อง ๔๒๗ ราย |
| `web/graph/money.json` | รายการโอนเงิน ๘๒ รายการ (ผู้โอน ผู้รับ ยอดเงิน วันที่ ผลวินิจฉัย และข้อความต้นฉบับ) สำหรับกราฟ “เส้นทางการเงิน” |
| `web/build.py` | รวมข้อมูล ตรวจว่าทุกประโยคตรงกับเอกสารคำต่อคำ หาเลขหน้า แล้วสร้าง `index.html` |
| `web/pages.py` | แปลง PDF เป็นภาพหน้า `web/pages/pNNN.jpg` และหาบรรทัดข้อความ |
| `web/segs.py` | หากลุ่มคำ (คำที่คั่นด้วยช่องว่าง) ในภาพสแกนแต่ละหน้า → `web/pages/segs.json` |
| `web/align.py` | จับคู่คำในข้อความกับกลุ่มคำในภาพ เพื่อวางไฮไลต์ให้ตรงประโยค |

## เว็บเพจทำอะไรได้

- กราฟบุคคลและความเชื่อมโยง (ถ้อยคำพยาน คำกล่าวหา การกระทำ คำชี้แจง ผลวินิจฉัย คำสั่ง) เลือกดูทีละประเด็นได้
- ทุกประโยคคัดจากเอกสารตามต้นฉบับ พร้อมเลขหน้า คลิกแล้วเปิดหน้านั้นใน PDF พร้อมไฮไลต์ประโยค
- รายชื่อบุคคล คลิกดูว่าแต่ละคนพูดถึงใคร หรือใครพูดถึงอย่างไร
- กล่อง "ผลการพิจารณา" ของแต่ละกรณี (คำสั่งของ กกต. และข้อสรุปจากการวินิจฉัย)

## สร้างใหม่

ต้องมี Python 3 พร้อม PyMuPDF, Pillow และ NumPy

```bash
cd web
python pages.py   # ภาพหน้า + lines.json (ทำครั้งเดียว)
python segs.py    # กลุ่มคำในภาพ → pages/segs.json
python build.py   # ตรวจข้อความ + สร้าง index.html
```

เปิดดูในเครื่อง: `python -m http.server -d web 8790` แล้วเข้า http://localhost:8790
